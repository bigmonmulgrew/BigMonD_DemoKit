Places two new button nexty to the play button

Button 1 reloads the domain
Button 2 reloads the domain and enters play mode

When importing this module will offer to disable domain reloadiing when entering play mode.
This means the default play mode will be faster but if domain reload is requried there is also a convenient button.

Take care, if you do not understand the implications of disabling domain reloading, do not disable it. It can cause issues with static variables and other things that are not reset when entering play mode.
